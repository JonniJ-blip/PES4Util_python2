4. ИГРОКИ КОМАНДЫ
4.1. Ссылки на игроков в блоке команды
В блоке команды (подблоки) хранятся только ID игроков (PlayerRef), а не полные данные.

Адрес	Размер	Описание	Статус
В подблоке 33 08	...	ID игроков состава	⚠️ Гипотеза
В Record Array	4 байта	ID игрока (в некоторых записях)	⚠️ Гипотеза
4.2. Полные данные игроков
Полные данные игроков (имя, атрибуты, возраст, рост, вес) хранятся в отдельной области или другом файле (OptionFile).

Адрес	Размер	Описание	Статус
0x09A000	124×32	Основной состав (имена, статы)	✅ Известно
0x0B5000	124×32	Дополнительный состав	✅ Известно
Структура блока игрока (124 байта):

Смещение	Размер	Описание	Формат
0x00-0x1F	32	Имя игрока	UTF-16LE
0x20-0x2F	16	Имя на футболке	ASCII
0x30-0x33	4	Счетчик версии	uint32
0x34-0x46	19	Прогресс атрибутов	Закодирован
0x47	1	Статус/форма	6, 22, 74, 10
0x48-0x49	2	Неизвестно	⚠️
0x4A	1	Травма/усталость	8 = здоров
0x4B-0x4F	5	Неизвестно	⚠️
0x50-0x57	8	Указатели	uint32
0x58-0x5B	4	Статистика	Голы/матчи
0x5C-0x5F	4	Временная метка	⚠️
0x60-0x63	4	Padding	часто DD DD DD
0x64-0x67	4	Указатель	⚠️
0x68-0x6B	4	Padding	-
0x6C-0x6F	4	Контрольная сумма + возраст	-

# Запись статистики турнира (0x28 байт)
RECORD = {
    'slot_marker': bytes[0:8],     # FF FF ... = занят
    'tournament_id': bytes[8:12],  # ID турнира
    'status': bytes[12:16],        # статус/флаги
    'unknown1': bytes[16:18],
    'unknown2': bytes[18:20],
    'unknown3': bytes[20:22],
    'points': bytes[22:24],        # ОЧКИ!
    'unknown4': bytes[24:26],
    'unknown5': bytes[26:28],
    'matches': bytes[28:30],       # СЫГРАНО МАТЧЕЙ!
    'unknown6': bytes[30:32],
    'unknown7': bytes[32:34],
    'unknown8': bytes[34:36],

    'wins_draws': bytes[38:40],    # ПОБЕДЫ (мл. байт) + НИЧЬИ (ст. байт)
